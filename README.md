# 筆記內頁產生器

一個純前端的筆記內頁產生工具，無需安裝，直接用瀏覽器開啟即可使用。

## 功能

- **四種版型**：橫線、方格、點陣、康乃爾
- **紙張設定**：A4 / A5 / B5 / Letter / 正方形 / 自訂尺寸，支援橫向／直向
- **樣式調整**：邊距、行距、線條粗細、邊框寬度、頁首高度
- **色彩系統**：極簡、文青莫蘭迪、牛皮紙三組色票，支援自由選色
- **頁首元素**：標題欄、日期欄（可選）
- **模板儲存**：設定存於瀏覽器 localStorage，下次開啟可直接載入
- **匯出**：PNG（300dpi）、PDF
- **功能導覽**：首次進入自動開啟，或點右上角 💡 重新查看

## 使用方式

直接下載 `index.html`，用任何瀏覽器開啟即可
